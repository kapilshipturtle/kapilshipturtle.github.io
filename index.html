Shopify app · bulk sync

Catalog import at scale

Senior developer and team lead on a public multi-vendor marketplace app.

View the app on Shopify →

Problem

Merchants needed to import and edit very large catalogs without losing variants or metafields on a partial update.

What I built

A GraphQL Admin API pipeline on Laravel queues and Redis, with full-state payload guards and webhook sync that holds up under bulk load.

Result

Up to ~400K rows per run, with a per-row failure report merchants can act on.

Shopify app · payouts

Refunds that reach the right vendor

Same marketplace app: commission, payouts and Stripe Connect onboarding.

Problem

A refund on a multi-vendor Shopify order has to lower the correct vendor's order and payout, including shipping and discounts.

What I built

Refund, shipping-refund and discount splits per vendor, with a rule that money already invoiced or paid is never rewritten.

Result

Vendor payouts follow the refund, and already-paid payout lines stay intact.

Laravel · Vue · billing

AI image billing app

Laravel 12, Vue 3, Inertia, Tailwind, PostgreSQL. Built test-first.

Live demo (free sign-up) → · Code

Problem

Charge users provider cost + 25% when the final price is only known after a slow, sometimes-failing job.

What I built

Credit holds in a ledger, idempotent retries, and signed webhooks with de-duplication and out-of-order handling.

Result

Billing totals matched the provider's own usage report exactly; 93 passing tests.
